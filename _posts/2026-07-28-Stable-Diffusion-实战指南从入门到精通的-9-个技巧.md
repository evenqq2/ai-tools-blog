## 技巧 1：结构化提示词
> **核心公式**：`角色 + 任务 + 背景 + 约束 + 格式 + 示例`

```markdown
# 万能模板
你是一位 资深设计师。
任务：分析数据。
背景：{你的具体场景}。
约束：{字数/格式/风格/禁用词}。
输出格式：{Markdown/JSON/表格/要点}。
示例：{给 1-2 个高质量例子}。
```

**实测对比**：
- 普通提示词：输出泛泛而谈
- 结构化提示词：可直接交付使用

## 技巧 2：关键信息锚定
- 对话超过 10 轮 → 新开会话 + 喂关键摘要
- 超长文档 → 先让 AI 生成摘要/大纲，再针对性提问
- 关键数据/结论 → 显式要求「在回复开头重申」

## 技巧 3：文件+提问
- 发截图 + 「帮我分析这个界面的交互问题」
- 传 PDF + 「提取核心论据做成表格」
- 录语音 + 「整理成会议纪要」

## 避坑清单

❌ 不要：「帮我写个方案」（太模糊）
✅ 要：「你是资深PM，帮我写一个SaaS产品的PRD，目标用户是中小企业HR，核心功能是智能排班，输出Markdown格式，包含背景/目标/功能列表/非功能需求/里程碑」

❌ 不要：一口气扔 100 页 PDF 让总结
✅ 要：先问「这文档核心论点是什么」，再针对性提取

❌ 不要：信任 AI 所有输出
✅ 要：关键数据/代码/结论 **必人工复核**

## 进阶：构建你的 Prompt 库

建立个人/团队提示词库，分类管理：
```
prompts/
├── writing/      # 写作类
├── coding/       # 编程类
├── analysis/     # 分析类
├── planning/     # 策划类
└── templates/    # 通用模板
```

每次用完好的 prompt 存进去，下次直接调用，**复利效应**惊人。
